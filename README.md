# Sobre o repositório `proj-sabor_express`:
Um menu em CLI que simula uma aplicação na qual o usuário pode cadastrar, listar e consultar restaurantes, verificando se estão em atividade ou não. 
O usuário também pode alterar o status de um restaurante. 
Nesse projeto trabalhei além dos fundamentos básicos, arquitetura modular, controle de fluxo, estruturas de dados e documentação inline.
